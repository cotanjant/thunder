Free installers and portable builds for Windows, Mac and Linux.

v1.0.1 Latest

Fixes the Windows installer so the Desktop and Start Menu shortcuts are created in the right places with the Thunder app icon.

Windows

Download the .msi, double-click it, and follow the wizard. It asks about Start Menu and desktop shortcuts. After that, start it from the desktop icon. No terminal needed.

Download Windows (.msi)

Mac

Open the .dmg, drag Thunder into Applications, then double-click it there. Works on Intel and Apple Silicon Macs.

Download Mac (.dmg)

Linux

Download the .AppImage, right-click it, allow launching (or run chmod +x once), then double-click it. One file, nothing to install. Terminal users can use the installer script or a plain binary instead:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/cotanjant/thunder/releases/download/v1.0.1/thunder-installer.sh | sh
Download AppImage Linux binary (.tar.xz)

Older system (Ubuntu 20.04 era, Mint 20, Debian 11)? Use the old-glibc build instead, same program:

Old-Linux AppImage Old-Linux binary (.tar.xz)

First launch warnings

The app is not signed with Apple or Microsoft, so both systems warn on first run. On Mac, right-click Thunder and choose Open, then confirm. On Windows, click More info in the SmartScreen popup, then Run anyway. You only do this once.
